# 상가 입지 리포트 (마포구)

마포구 주소를 넣으면 주변 상가, 행정동 유동인구, 적정 월세를 바탕으로 창업 입지 점수와 상담 리포트를 보여 줍니다.

- `index.html` : 리포트 화면
- `mapo-data.js` : 화면이 쓰는 자료 (build_data.py가 만듭니다)
- `build_data.py` : 자료 생성 프로그램
- `원본데이터/` : 유동인구(서울시 상권분석서비스), 임대동향(한국부동산원) 원본 CSV

## 자료 업데이트
- 상가정보: 2·5·8·11월 5일에 GitHub Actions가 공공데이터포털 API로 자동으로 받아 갱신합니다 (Secrets의 `DATA_GO_KR_KEY` 필요).
- 유동인구·임대동향: 새 분기 CSV를 `원본데이터/`에 올리면 다음 자동 실행 때 반영됩니다.

자료: 소상공인시장진흥공단 상가(상권)정보, 서울시 상권분석서비스, 한국부동산원 상업용부동산 임대동향조사.
점수는 상담 참고용이며 계약 판단을 대신하지 않습니다.
